# Решения заданий

## 1. Логическое выражение при X = 4

**Условие:** Определить значение логического выражения:

\[
(X > 3) \lor (X < 3) \lor (X < 1), \quad X = 4
\]

### Решение

**Шаг 1.** Подставим значение X = 4 в каждое условие:

- X > 3: 4 > 3 — истина (1).
- X < 3: 4 < 3 — ложь (0).
- X < 1: 4 < 1 — ложь (0).

**Шаг 2.** Запишем полученное выражение:

\[
1 \lor 0 \lor 0
\]

Знак \(\lor\) обозначает логическую операцию «ИЛИ». Результат равен истине, если хотя бы один из операндов истинный.

**Шаг 3.** Вычислим результат:

\[
1 \lor 0 = 1
\]

\[
1 \lor 0 \lor 0 = 1
\]

**Ответ: 1 — истина.**

## 2. Утверждение о параллельных прямых

**Условие:** Если одна из двух параллельных прямых пересекает данную плоскость, то и другая прямая пересекает эту плоскость.

### Решение

Это утверждение неверно.

пусть прямые \(a\) и \(b\) параллельны. Прямая \(a\) пересекает плоскость \(\alpha\), а прямая \(b\) параллельна этой плоскости и не имеет с ней общих точек.

Следовательно, одна прямая может пересекать плоскость, а другая параллельная ей прямая — не пересекать её.

**Ответ: утверждение неверно.**
